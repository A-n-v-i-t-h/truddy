# 01 — Structure marking (confirmed highs/lows, BOS, CHOCH)

## Rules practised
- Buying waves = impulse, selling waves = correction (bullish); never trade the retracement.
- **High confirmed** after a 2-candle retracement: 2 consecutive red candles, 2nd body closes below the 1st's low.
- **Low confirmed** when 1 candle CLOSES above that confirmed high (= BOS). In bullish structure the high is confirmed first.
- No new 2-candle retracement is looked for until the previous high is broken. Bearish = mirror.
- Confirmed low = last support (level 2); a 2-candle close below it = CHOCH.
